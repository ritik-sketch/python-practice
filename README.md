# Python Practice

Exercises I write while learning Python for test automation. Small, focused scripts: one concept or problem per file. Some early files follow online tutorials; newer ones are my own practice and interview-prep problems.

## Folders

- python_basics/ - variables, operators, conditionals, loops, functions, strings, lists
- basics/, math_programs/, patterns/ - small classic programs (factorial, fibonacci, palindrome, star patterns)
- data_structures/ - stack, linked list
- oops/ - classes and sorting practice
- file_handling/ - reading and writing text files
- 100_days_challenge/ - daily problem-solving practice (in progress)
- interview_questions/ - notes and use cases
- projects/ - small projects (coming as I go)

## How I use this repo

New practice goes in dated or numbered files; each commit is one session. Related: my test automation framework at https://github.com/ritik-sketch/playwright-pytest-framework
